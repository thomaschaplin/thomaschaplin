I look after Kubernetes and AWS platforms by day and build small tools in Go, TypeScript and Rust when I'm not. I started out in testing, which still shapes how I build things.

### Things I've made

- [**kmortem**](https://github.com/thomaschaplin/kmortem): a Kubernetes operator that keeps a record of why each node died (spot interruptions, Karpenter disruptions, drains), so you can still `kubectl get` it after the node is gone
- [**rust-counter-strings**](https://github.com/thomaschaplin/rust-counter-strings): generates self-describing strings to help with testing
- [**image-to-totp**](https://github.com/thomaschaplin/image-to-totp): turns QR code images into TOTP codes
- [**mock-inspect**](https://github.com/trayio/mock-inspect) and [**graphql-query-to-json**](https://github.com/trayio/graphql-query-to-json): testing tools I wrote and open-sourced at Tray
